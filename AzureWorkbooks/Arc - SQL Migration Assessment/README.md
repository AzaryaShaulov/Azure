# Azure Arc SQL Migration Assessment Workbook

The **Arc SQL Migration Assessment Workbook** provides a centralized view of SQL Server migration readiness across an Azure Arc-enabled environment.

Microsoft's native Migration Assessment experience is excellent for reviewing the details of an individual SQL Server or database. However, when managing a larger SQL estate, reviewing assessments one server at a time can become difficult and time-consuming.

This workbook is designed to solve that problem by bringing migration assessment data together into a **single estate-wide view**.

## Why Use This Workbook?

Instead of opening each SQL Server individually to review its Migration Assessment, the workbook allows migration teams to quickly understand the overall migration posture of the environment.

It helps answer questions such as:

- How much of the SQL estate has been assessed?
- Which SQL Servers are ready for migration?
- Which workloads have blockers or incomplete assessments?
- What Azure SQL targets and SKUs are being recommended?
- Which assessments are missing or outdated?
- What are the estimated Azure costs across the migration portfolio?

The main advantage is the ability to **compare and analyze many SQL Servers at once**, rather than working through assessments individually.

## Export Results

Results can be exported to Excel for additional analysis, reporting, migration-wave planning, financial analysis, or integration with existing project tracking processes.

## Native Assessment vs. Workbook

| Native Migration Assessment | Arc SQL Migration Assessment Workbook |
| --- | --- |
| Best for detailed analysis of one SQL Server | Best for analyzing the overall SQL estate |
| Review servers individually | Review many servers together |
| Detailed technical assessment | Consolidated migration planning view |
| Per-resource experience | Estate-wide visibility |
| Manual comparison between servers | Easier comparison and prioritization |
| Limited downstream analysis | Exportable for Excel and further analysis |

The workbook does **not replace Microsoft's Migration Assessment engine**. It uses the assessment information generated by Azure Arc and presents it in a way that is easier to consume at scale.

## From Assessment to Migration Planning

For large environments, the challenge is often not generating an assessment. The challenge is turning hundreds of individual assessments into an actionable migration plan.

The workbook helps bridge that gap:

```text
Azure Arc Migration Assessment
        ↓
Individual SQL Assessment Data
        ↓
Arc SQL Migration Assessment Workbook
        ↓
Estate-Wide Visibility
        ↓
Compare & Prioritize
        ↓
Export & Further Analysis
        ↓
Migration Planning
```

## Summary

Microsoft Migration Assessment provides detailed migration guidance for individual SQL workloads.

This workbook brings those assessments together so migration teams can understand, compare, and plan the migration of the entire SQL estate from one place.
